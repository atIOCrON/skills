# Clean Documentation Changes

Apply the repository’s documentation policy.

Keep only durable knowledge that cannot be readily inferred from code, configuration, schemas, tests, CLI help, or diagnostics. Prefer deletion or a shorter rule.

Preserve controlled vocabularies, authority boundaries, external constraints, rationale, and unenforced safeguards when omission could cause error.
